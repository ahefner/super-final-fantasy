#  Map Select's list, in the order the screen shows it (tools/genmaps.py).
#
#  A line: where the map comes from, then the name the screen shows.
#
#    vanilla NAME           the game's map; must be first, and choosing it
#                           leads on to the map edits
#    mirror-lr NAME         the game's map mirrored left to right
#    ffm STEM NAME          a map drawn in this directory: STEM.ffm, its
#                           256 x 256 tiles one byte each (FFHackster's and
#                           FFR's format), and STEM.toml, the places the
#                           tiles do not show -- the start, Bikke's ship,
#                           the airship, the bridge, the canal, the docks.
#                           Its entrances, exits and encounter zones come
#                           from the tiles.  One of FFR's maps becomes one:
#                             python3 tools/genmaps.py --import POOL ID STEM
#
#  At most 16 maps.  The screen shows them in two columns, the first half
#  (rounded up) on the left: a name on the left is at most 13 letters, on
#  the right at most 12.  A drawn map changed, the build works out its logic
#  again (tools/gengraph.py --stale; commit maps/graph/ with it).
